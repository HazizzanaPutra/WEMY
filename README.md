## 📖 Deskripsi

WEMY (Website Pemesanan Membership Yoga Berbasis Web) merupakan aplikasi berbasis web yang dikembangkan sebagai Proyek Akhir Program Studi D3 Teknik Informatika.

Aplikasi ini bertujuan untuk membantu studio yoga dalam mengelola proses membership secara digital, mulai dari registrasi pengguna, pembelian paket membership, verifikasi pembayaran, pengelolaan jadwal yoga, hingga penyajian laporan transaksi.

---

## ✨ Fitur Utama

### 👤 User / Member

- Registrasi akun
- Login
- Melihat paket membership
- Melihat detail paket
- Checkout membership
- Upload bukti pembayaran
- Dashboard Member
- Riwayat Pembelian
- Jadwal Yoga
- Informasi status membership
- Perpanjangan membership
- Membership otomatis Expired

---

### 👨‍💼 Administrator

- Login Admin
- Dashboard Admin
- Manajemen Member
- Detail Member
- Manajemen Paket Membership
- Manajemen Jadwal Yoga
- Verifikasi Pembayaran
- Approve Membership
- Reject Membership
- Laporan

## 🚀 Cara Menjalankan

1. Clone repository.

```
git clone https://github.com/HazizzanaPutra/WEMY.git
```

2. Buka menggunakan Visual Studio 2022.

3. Restore NuGet Package.

4. Import database SQL Server.

5. Jalankan aplikasi menggunakan IIS Express.
